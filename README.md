# 📜 Cordel Moderno

Projeto desenvolvido como parte do curso de **HTML5 e CSS3** do [Curso em Vídeo](https://www.youtube.com/@cursoemvideo), ministrado por Gustavo Guanabara.  

---

## 🎯 Objetivo
Criar uma página simples que simula o estilo de um **cordel moderno**, utilizando imagens de fundo com efeito parallax e trechos de poesia de Milton Duarte.

---

## ⚙️ Tecnologias Utilizadas
- **HTML5**: estruturação do conteúdo.  
- **CSS3**: estilização e aplicação do efeito parallax.
